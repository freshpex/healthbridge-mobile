# HealthBridge Mobile

Expo React Native + TypeScript mobile app for HealthBridge.

## Setup

```bash
npm install
cp .env.example .env
npm run start
```

Start with Expo Go for development. The app uses seeded presentation data and can call the backend with `EXPO_PUBLIC_API_URL`.

## Commands

```bash
npm run lint
npm run typecheck
npm run test
npx expo-doctor --verbose
npx expo prebuild --clean
```
